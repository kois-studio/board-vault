# Security policy

Please do not open a public issue for a suspected vulnerability or include
credentials, tokens, personal data, or exploit details in a pull request.

Use GitHub's private vulnerability-reporting or security-advisory channel for
this repository. If that channel is unavailable, contact the repository owner
through a private GitHub message and include:

- the affected version or commit;
- a concise description and impact;
- reproduction steps that use synthetic data only; and
- a suggested mitigation, if known.

Do not test against deployed services or another person's account. Maintainers
will acknowledge a report, assess severity, coordinate a fix, and publish
credit only with the reporter's consent.

Before release, maintainers must scan the staged tree and the complete public
history, rotate any credential that may have been exposed, and verify that
fixtures and documentation contain no personal data.
