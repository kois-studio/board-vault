# Work queue

Work is tracked in **[GitHub Issues](https://github.com/kois-studio/board-vault/issues)**.
This file only points there.

- List open work: `gh issue list`, or filter with `--label "priority:P1"` or
  `--label "area:backend"`.
- New work: open an issue with the *Work item* or *Bug report* template. It asks
  for the goal, scope, acceptance criteria, and verification.
- Labels: `needs-triage` (new), `blocked`, `priority:P1`–`P3`, and `area:*`.
